## 🧑‍💻 About Me

> *"Clean code. Scalable architecture. Delightful experiences."*

I'm a **Software Engineer** specializing in both **Mobile** and **Web** — building high-performance, cross-platform apps for **iOS**, **Android**, and **Desktop**, as well as modern web experiences with **React** and **Next.js**. I've shipped production-ready products across legal, education, and e-commerce domains, with deep expertise in real-time systems, payment integrations, and scalable backend APIs.

- 🔭 Currently building cross-platform mobile apps with **Flutter + BLoC** and web apps with **React / Next.js**
- ⚡ Passionate about **Clean Architecture**, **performance optimization**, and **UX polish**
- 🌍 Based in **Cairo, Egypt** — working remotely across global teams
- 🎯 Focused on scalable, maintainable, user-first products — across every platform
